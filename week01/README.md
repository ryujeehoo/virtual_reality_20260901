# 1주차 - Unity 6 설치 (Chapter 1)

가상현실 실습을 위해 Unity 6 엔진을 설치한다.

## 설치 체크리스트

### 1. Unity Hub 설치
- [ ] [unity.com/kr/download](https://unity.com/kr/download) 접속 후 계정 생성
- [ ] Windows용 `UnityHubSetup.exe` 다운로드
- [ ] 안내에 따라 Unity Hub 설치

### 2. 요금제 확인
- [ ] Personal 플랜으로 시작
- [ ] (해당 시) Unity Student로 학생 인증 → 추가 혜택 확인

### 3. 계정 로그인 및 라이선스 활성화
- [ ] Unity Hub 실행 후 계정 로그인
- [ ] 환경 설정 확인
- [ ] 라이선스 메뉴에서 "추가 또는 활성화" → 무료 Personal 라이선스 받기 → 약관 동의

### 4. Unity 버전 설치 (필수: 6000.3.22f1 LTS)
- [ ] 설치 → 에디터 설치 → 정식 릴리스 → **6000.3.22f1 LTS** 선택
- [ ] 기존에 다른 버전이 설치되어 있어도 6000.3.22f1 LTS는 반드시 추가 설치

### 5. 설치 옵션
- [ ] Microsoft Visual Studio Community 2022 또는 2026 (이미 설치되어 있으면 자동 체크됨)
- [ ] Android Build Support
  - [ ] Android SDK & NDK Tools
  - [ ] OpenJDK
- [ ] Documentation → 한국어 언어팩
- [ ] 모든 옵션 체크 후 계속 → 약관 동의 후 설치
